Streuph's Maze — current world blueprint and future concepts
==========================================================

Current scope: six implemented eight-level worlds (48 levels), plus the
13-level Prologue = 61 shipped-source levels. Worlds 7 and 8 below are future
concepts only, not supported packs/mechanics. Editor work is tracked separately;
see docs/level-editor.md for its current authoring workflow.
The accepted V2 specs in openspec/specs/ and Tile Mechanics Reference control
behavior; this is the authoring/progression index, not an alternate ruleset.
Existing V2 deltas are synchronized; evidence and release approval remain separate.

Golden Rules
------------
• Visual minimalism: inspectable geometric forms, clear cardinal exit arrows,
  current carrier/lock/contact state, no unnecessary visual language.
• Early safety: levels 1–3 must have no unintended irreversible playing-state
  softlocks. Visible terminal ray mistakes are a separate restart lesson; no
  intended winning route continues after failure. Record any deliberate reset
  exception rather than assuming solver success proves safety.
• Determinism: synchronous atomic commits, signal → transport → ordinary work,
  entry-only victory, common crate-pending/dot-failed closure. Animation never
  changes gameplay. White/Red/Green/Blue only; no implicit mobility from tint.
• Bounds: 2–16 columns, 1–9 rows; top-first YAML, bottom-left A1. Large stable
  envelopes may include wall padding; do not claim padding creates difficulty.
• Canonical progression: tutorial; two beginner variants; familiar-mechanic
  combination; intermediate homage; sparse/asymmetric remix; hard sequence;
  mastery. Prologue is a separate 13-lesson introduction, not an eight-level world.
• Every PAR must be minimum-proved and replayed through the real resolver.
  Record wrong pushes, optional/scenery elements, source/gate necessity,
  comparison completeness, and deliberate deviations from historical concepts.

Current evidence: v2-pack-certification.md, v2-pack-proofs.json, and each linked
route review. All 61 source minima currently prove/replay; final repository,
Chromium, reference audits, and accepted-spec approval are separate gates.

Future concepts — UNIMPLEMENTED, not authoring contracts
------------------------------------------------------
The original World 7/8 concepts below remain design ideas only. They do not
allocate registered IDs, authorize an editor, or add inventory/crumble/timers to
the current engine. Any implementation needs a separately approved scoped change.

🐍 World 7: Catrap Collapse (The Hamiltonian Trail Paradigm)
	•	Source Inspiration: Catrap / Pitman (Asmik, 1990)
	•	Core Mechanic: Traversing paths where exited floor tiles crumble into voids, demanding a complete Hamiltonian traversal.
Level	Type	Grid Size	Description & Mechanics
1	Tutorial	5x5	Simple path where every single tile must be stepped on once before exit.
2	Beginner	7x5	Branching path with one dead-end trap.
3	Beginner	8x8	Crossing back over via teleporters to avoid crumbling voids.
4	Combinatory	10x8	Crumbling floors paired with pushable blocks to bridge gaps.
5	Intermediate	12x8	Homage: Catrap Stage 10 subterranean cavern.
6	Odd / Remix	16x4	The 2x16 Tightrope: Zero margin for side-stepping errors.
7	Hard	16x9	Complex labyrinth where block positioning dictates valid floor survival.
8	Master	16x9	The Void Abyss: 16x9 full-grid elimination puzzle where only one exact sequence succeeds.
🏛️ World 8: Solomon's Key (The Vanishing Metronome Paradigm)
	•	Source Inspiration: Solomon's Key (Tecmo, 1986)
	•	Core Mechanic: Tactical timing, vanishing/summoning floor tiles, and rhythmic block state changes.
Level	Type	Grid Size	Description & Mechanics
1	Tutorial	5x5	Step across timed vanishing floor tiles to reach the exit.
2	Beginner	7x5	Rhythmic obstacle timing combined with a basic wall switch.
3	Beginner	9x6	Synchronizing player movement with pulsing tile cycles.
4	Combinatory	10x8	Vanishing tiles intersecting with conveyor belts and crate docks.
5	Intermediate	12x8	Home: Solomon's Key Room 5 (The Zodiac Chamber).
6	Odd / Remix	16x6	The Metronome Corridor: 16-wide rhythmic pulse gauntlet.
7	Hard	16x9	Multi-phase timing puzzle requiring exact turn counting.
8	Master	16x9	The Oracle's Sanctum: The ultimate synthesis of timing, color auras, and global flip-flops.
